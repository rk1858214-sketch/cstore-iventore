# C Store Inventory Live Project

مشروع نظام الجرد Live مربوط بـ Supabase.

## الملفات

- `index.html` واجهة المشروع الأساسية
- `css/style.css` تنسيقات وألوان المشروع
- `js/app.js` كل وظائف النظام والربط مع Supabase
- `assets/logo.jpg` لوجو C Store

## التشغيل

افتح `index.html` مباشرة في المتصفح للتجربة.

## النشر على GitHub + Vercel

ارفع كل الملفات والمجلدات كما هي:
- index.html
- css
- js
- assets
- README.md

ثم اربط Repository مع Vercel بدون Build Command.
